# Engineering Knowledge Base

Персональная база знаний для накопления инженерной экспертизы, анализа профессионального роста и подготовки к уровню Senior Engineer.

---

# Назначение

Knowledge Base используется для:

- накопления инженерного опыта;
- хранения результатов расследований;
- сохранения Lessons Learned;
- ведения Root Cause Analysis;
- анализа профессионального роста;
- улучшения качества постановки вопросов;
- построения собственного инженерного Wiki;
- подготовки к уровню Senior Engineer.

---

# Быстрый старт

1. Прочитайте KNOWLEDGE_BASE_STRUCTURE.md
2. Изучите KNOWLEDGE_BASE_WORKFLOW.md
3. Создайте первый Daily Report
4. Выполните первый Professional Growth Analysis

---

# Каталоги

## daily
Ежедневные отчёты и аналитика.

## weekly
Еженедельные обзоры и ретроспективы.

## monthly
Ежемесячный анализ развития.

## prompts
Промпты для Copilot.

## templates
Шаблоны документов и отчётов.

## rca
Root Cause Analysis и расследования.

## lessons-learned
Накопленный инженерный опыт.

## knowledge-base
Постоянная инженерная Wiki по технологиям.

## playbooks
Пошаговые инструкции и алгоритмы действий.

## projects
Карточки проектов и справочная информация.

## growth
Skill Matrix, Roadmap и Middle → Senior Gap Analysis.

## inbox
Временные заметки и идеи.

## archive
Архив материалов.

## logs
Служебные логи.

---

# Основные принципы

- Проекты временные. Знания постоянные.
- Каждое расследование должно создавать знания.
- Повторяющиеся действия должны становиться Playbook.
- Повторяющиеся знания должны попадать в Knowledge Base.

# Обновление системы

Перед обновлением рекомендуется:

```powershell
git add .
git commit -m "Backup before update"
```

После обновления проверить:

- prompts/
- templates/
- growth/
- README.md
