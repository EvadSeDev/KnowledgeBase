# Knowledge Base Structure

## Назначение
Система накопления инженерных знаний и профессионального роста.

## daily
Что: ежедневные отчеты.
Зачем: фиксация опыта дня.
Хранить: Daily Reports.
Не хранить: RCA и статьи.

## weekly
Что: недельные обзоры.
Зачем: анализ прогресса.

## monthly
Что: месячные обзоры.
Зачем: отслеживание развития.

## prompts
Промпты для Copilot.

## templates
Шаблоны документов.

## rca
Хранилище Root Cause Analysis.
Цель: не расследовать одну проблему дважды.

## lessons-learned
Накопленные выводы и уроки.

## knowledge-base
Инженерная Wiki по технологиям.

## playbooks
Пошаговые инструкции.

## projects
Карточки проектов.

## growth
Skill Matrix, Roadmap, Gap Analysis.

## inbox
Временные заметки.

## archive
Архив.

## Обновление структуры
- Новые каталоги добавляются через bootstrap-скрипт.
- Пользовательские данные не удаляются.
- Перед обновлением рекомендуется Git commit.
